## Primer Octicons

mkLINK includes icon assets from **Primer Octicons**, the open-source icon set maintained by GitHub's Primer project.

Project:
- Primer Octicons: https://primer.style/octicons/
- Source repository: https://github.com/primer/octicons

The original SVG assets used by mkLINK are retained under `assets/octicons/`. Some PNG files in the same directory are build assets derived from those SVG files for Win32/GDI rendering.
